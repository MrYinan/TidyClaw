# Robot Cleaner Configs

This directory contains runtime, scenario, and service-task ontology configs for the OpenClaw + AI2-THOR tidy robot.

- `robot_cleaner_runtime.json`: runtime map backend configuration.
- `scenarios_v2.json`: benchmark and backend scenario definitions.
- `service_task_ontology_v2.json`: online YOLO task ontology.
- `service_task_ontology_v3.json`: training and regression ontology.
